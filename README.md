# 字幕方块模组 (SubtitleScreen Mod)

一个基于 Fabric 的 Minecraft 模组，添加了一个可以在大屏上显示字幕的方块。

## 功能特性

- **字幕方块**: 一个特殊的方块，可以显示自定义字幕
- **权限控制**: 仅允许 OP 权限玩家或单人/局域网模式玩家使用
- **多种触发方式**: 支持玩家进入世界触发和红石触发
- **自定义样式**: 支持 16 种颜色、3 种字体（微软雅黑、宋体、楷体）
- **彩虹文字**: 支持彩虹色文字效果
- **区块强加载**: 自动强制加载区块以确保功能正常运行

## 安装方法

1. 安装 Fabric Loader
2. 将模组文件放入 `mods` 文件夹
3. 启动游戏

## 使用方法

1. 从创造模式物品栏的"字幕方块"标签页中获取字幕方块
2. 放置方块后右键打开设置面板
3. 配置字幕内容、颜色、字体、触发方式等
4. 保存设置即可生效

## 字幕语法

- 使用 `id:"player"` 可以显示触发玩家的名称
- 示例：`欢迎, id:"player"` 会显示为 `欢迎, 玩家名称`
